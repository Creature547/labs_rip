# Лабораторная работа 5

SPA на React и TypeScript для просмотра услуг отопительного оборудования. Данные используются из локальной коллекции mock-объектов; подключение к API, базе данных, S3 и Redux отсутствует.

## Запуск

```bash
npm install
npm run dev
```

## Локальные медиафайлы

Фото поместить в `public/media/images`, видео - в `public/media/videos`.

| Услуга | Фото | Видео |
| --- | --- | --- |
| Цилиндрическая печь | `cylindrical-stove.png` | `cylindrical-stove.mp4` |
| Бойлер косвенного нагрева | `indirect-boiler.png` | `indirect-boiler.mp4` |
| Электрическая печь | `electric-stove.png` | `electric-stove.mp4` |
| Теплогенератор | `heat-generator.png` | `heat-generator.mp4` |

## Страницы

- **Лента**: одно локальное видео, данные услуги, кнопка «ещё» и переход к следующей услуге.
- **Плитка**: карточки с локальными фото, поиск по названию и сортировка по дате или цене.
- В нижней навигации видны «Лента», «Добавление», «Плитка» и «Вход». В ЛР5 доступны только лента и плитка.

При пустом `imagePath` или `videoPath` выводится локальное изображение или видео по умолчанию.
